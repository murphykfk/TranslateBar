# TranslateBar

为自带 OpenAI API Key 的用户打造的 macOS 常驻翻译工具，覆盖输入替换、划词阅读和视频译声。

A native macOS menu bar translator for people with their own OpenAI API key: translate the current paragraph in place, read selected text, and listen to translated Mac audio.

这是一个自己在用、按需更新的个人开源项目。欢迎 Fork、修改自己的版本，或提交 Issue / PR；不承诺固定更新节奏或问题响应时限。

## 能做什么

- **输入翻译**：输入完成并结束输入法选词后，快速按连续空格，用译文直接替换光标所在段落。默认四次，可设置两次或三次。回车分段，其他段落保持原样，空段落跳过。成功后不弹完成通知。
- **划词翻译**：选中文字后显示译文，也可用快捷键触发。点击外部、取消选择或切换应用后自动隐藏；移入浮窗可继续阅读和复制。不使用 OCR。
- **视频译声**：捕获所选浏览器或应用正在播放的声音，通过 OpenAI 实时翻译并播放译声，支持原声静音、悬浮字幕、字号、译声音量和延迟显示。可用于观看 YouTube 等视频。
- **统一设置**：各功能可独立开关；输入与划词共享持久化文字缓存；支持目标语言、文字模型、自定义模型和本地费用限额。

## 系统要求

- macOS **14.4 或更高版本**。
- 当前主要在 **Apple Silicon Mac** 上开发和验证；Intel Mac 尚未完整实机验证。
- 自己的 OpenAI API Key，以及可用的 API 额度和网络连接。ChatGPT 订阅不等于 API 额度。

## 下载安装

普通用户不需要 Xcode、Apple 开发者账号，也不需要自行签名。

1. 确认 Mac 使用 **Apple Silicon（M 系列芯片）**，系统为 **macOS 14.4 或更高版本**。可在苹果菜单 →“关于本机”查看。
2. 打开 [GitHub Releases 下载页](https://github.com/murphykfk/TranslateBar/releases/latest)，在 **Assets** 中下载以 `.dmg` 结尾的安装包；`Source code` 是源码，不是安装包。
3. 双击 DMG，将其中的 **TranslateBar.app** 拖到 **Applications（应用程序）**。如果已在运行旧版，先从菜单栏退出，再替换。
4. 等复制完成，弹出磁盘映像，再从访达的 **应用程序 → TranslateBar** 打开；后续也从这个位置启动。

**当前包采用临时签名（ad hoc），未使用 Developer ID 分发证书，未通过 Apple 公证。** 如果首次打开被系统拦截，请继续下面的步骤。

### 首次打开被 macOS 拦截时

以下方法适用于“无法验证开发者”“Apple 无法检查是否包含恶意软件”等身份验证提示，且你已确认安装包来自本仓库的 Releases。

1. **先从“应用程序”尝试打开一次 TranslateBar**。如弹出拦截提示，选择“完成”或“好”关闭提示，保留应用。
2. 打开苹果菜单 → **系统设置 → 隐私与安全性**（部分系统版本称“隐私与安全”），向下滚动到“安全性”区域。
3. 找到与 **TranslateBar** 对应的拦截记录，点击 **仍要打开（Open Anyway）**。
4. 若系统要求，使用 Touch ID 或 Mac 登录密码验证，并在再次出现的确认窗口点击 **打开**。
5. 如应用没有自动启动，再从 **应用程序 → TranslateBar** 打开，然后按下方引导设置。

没有“仍要打开”按钮时，先确认做过第 1 步，再重新查看系统设置。若仍然没有按钮，或提示“已损坏”“将损坏你的电脑”，请看 [完整安装与排障说明](docs/INSTALLATION.md)，不要把这些提示都当成普通开发者验证提示处理。

这是针对单个应用的打开确认，无需关闭 Mac 的全局安全检查。按钮名称可能随系统版本略有差异，见 [Apple 官方打开说明](https://support.apple.com/zh-cn/102445)。

## 第一次设置与试用

1. 在引导中粘贴自己的 **OpenAI API Key**，点击 **保存密钥**，确认显示“已保存到本机钥匙串”后继续。保存只存储 Key；可选的“测试连接”才会实际调用 API，并产生少量费用。
2. 点击 **前往授权…**，在 **系统设置 → 隐私与安全性 → 辅助功能**（部分版本称“无障碍”）为 TranslateBar 开启权限；列表没有应用时，点“＋”添加“应用程序”中的 TranslateBar。
3. 返回引导，检查 **辅助功能：已授权**、**键盘监听：运行中**。若系统要求输入监控，再到“隐私与安全性 → 输入监控”开启。系统要求重新打开应用时，退出并重新打开后继续。
4. 完成引导后，可到 **菜单栏图标 → 设置… → 常规 → 翻译练习…** 试用。输入中文、确认输入法选词，将光标留在段落末尾，快速按 **四次空格**；原文应被英语译文替换。次数可在“输入翻译”中改为两次或三次。
5. 只用文字翻译时，无需录制权限。要使用译声，先播放视频，再到 **设置… → 实时译声** 选择“声音来源”并开始，按提示为 TranslateBar 开启 **录屏与系统录音**；当前取音接口仅开启“系统录音”仍不足，具体名称随 macOS 版本可能不同。应用只接收音频，不接收或上传画面。

关闭设置窗口后，应用继续在 **屏幕顶部菜单栏** 运行。API Key 不需要填写在源码或 `.env` 中；语言、模型和费用限额可在设置中继续调整。翻译练习和实际翻译可能产生 API 费用；输入与划词缓存命中时不调用 API。

完整的权限检查、划词与译声试用、校验文件用法和常见问题见 [安装与首次打开指南](docs/INSTALLATION.md)。

**升级或重装后不能翻译？** 0.4.6 起会自动检查当前版本的文字权限，并显示恢复引导；即使系统开关已开启，也可能需要移除旧记录后重新添加当前 App。点击菜单栏的“恢复输入与划词翻译…”可继续处理，详见[升级后的权限恢复](docs/INSTALLATION.md#升级或重新安装后原来的权限开关已经开启却不能翻译)。

## 默认操作

| 操作 | 默认方式 |
| --- | --- |
| 翻译并替换当前段落 | 快速按四次空格，可改为两次或三次 |
| 翻译选中文字 | 鼠标拖选后自动显示，或 `⌃⌥T` |
| 撤销上次翻译替换 | `⌃⌥Z` |
| 开始 / 停止译声 | `⌃⌥V` |

快捷键可以重新录制。撤销仅在原输入框仍聚焦、内容未再次改变时执行。

输入默认译为英语，划词默认译为简体中文，译声默认输出中文。文字原文默认自动识别，日语、法语等不需要分别开启；可以为输入和划词分别设置固定目标或智能互译。自动识别短词、混合文本时可能不够准确，可手动指定原文语言。

## API、费用与隐私

- 翻译请求直接发送到 OpenAI 官方 API，不经过项目自建服务器。用户自行承担自己的 API 费用。
- Key 仅保存到本机钥匙串；不会随源码或安装包分发，也不写入设置、文字缓存和费用账本。换电脑需要重新配置。
- 文字翻译会发送本次待翻译的段落或选中文字。译声会发送所选应用的音频；当前实现不接收或上传画面，也不使用麦克风。
- 输入与划词缓存含原文和译文，保存在本机，重启后保留，可在设置中关闭或清空。缓存命中不调用 API；译声不缓存。
- 本地费用限额只控制本应用的预估费用，不能限制同一 Key 在其他软件中的支出，也不是 OpenAI 账户级硬上限。官方账单以 OpenAI 平台为准。
- 设置、缓存、费用账本和数值诊断位于 `~/Library/Application Support/TranslateBar/`，文件权限为 600。费用账本不记录原文；回填诊断只记录版本、时间、长度、范围和固定原因类别，不记录正文、译文、按键字符或 Key。
- 密钥获取：[OpenAI API Keys](https://platform.openai.com/api-keys)。用量与价格以 [OpenAI 平台](https://platform.openai.com/usage) 和 [官方价格](https://developers.openai.com/api/docs/pricing) 为准。

## 兼容范围与已知限制

主要验证过 Apple 备忘录、Chrome 输入框和可编辑的 WPS 文字正文；0.4.5 的微信聊天输入替换已获用户手动确认。兼容性仍取决于具体应用版本和编辑器提供的文本能力。

- 只能读取应用提供的文字选区，图片、扫描件和不可复制的文字不参与翻译。
- 回填前核对焦点、原文、光标和范围；无法安全回填时保留原文，显示可复制译文。
- 备忘录的混合字号、粗斜体、复杂结构可能触发格式保护。WPS 文字使用独立兼容路径；WPS 表格、演示和复杂排版尚未完整验证。
- 缺少标准文本接口的编辑器可能只能安全处理光标前当前行，不会回退为整页覆盖。
- 微信输入框未暴露标准焦点时，0.4.5 增加了草稿兼容路径，仅处理光标前当前行，不自动发送消息。需开启“常规 → 应用兼容性 → 增强取词与回填兼容”（默认开启）。飞书、豆包等客户端尚未在本轮单独验证。
- Word 正文的复制与粘贴兼容路径由“增强取词与回填兼容”控制。0.4.8 修正了把 Word 画布的禁用状态误判为文档只读的问题，编辑能力依据 Word 的粘贴和选区编辑命令核验。硬回车和手动换行前的文字保留；只读、受保护、混合字号或无法核实的选区会跳过。可编辑 Word 的完整回填仍待用户确认。
- 译声捕获的是所选应用，不能隔离浏览器单个标签页；请避免其他标签页同时发声。
- 网络和模型处理会带来译声延迟，不保证与视频口型同步。更换声音来源、输出语言或原声设置前请先停止译声。
- 终端和钥匙串默认排除；可按应用名称添加或恢复排除项。密码输入框始终跳过。

## 从源码构建

需要 Xcode 16 或更新版本的开发工具（Swift 6.0+、macOS SDK）、Python 3，以及 Git。

```sh
git clone https://github.com/murphykfk/TranslateBar.git
cd TranslateBar
zsh scripts/build.sh
open dist/TranslateBar.app
```

没有第三方 Swift 包依赖。构建脚本会生成图标和 `.app`，优先使用本机可用的 Apple 开发证书；没有可用证书时使用临时签名。也可以显式选择临时签名：

```sh
TRANSLATEBAR_SIGN_ID=- zsh scripts/build.sh
```

建议将应用放在固定位置使用。更换签名、位置或重建后，macOS 可能要求重新授予权限。本地构建与正式的 Developer ID 签名、公证发行是不同的步骤。
