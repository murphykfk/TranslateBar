# TranslateBar 安装与首次打开指南

按顺序完成：**下载安装 → 允许首次打开 → 保存自己的 API Key → 开启文字权限 → 试用**。译声的录制权限可以等实际使用时再开启。

普通用户无需 Xcode、Apple 开发者账号或自己的签名证书。当前下载包采用临时签名（ad hoc），未使用实名 Developer ID 分发证书，未通过 Apple 公证，因此首次打开可能被 macOS 拦截。

## 1. 下载并放入“应用程序”

1. 在苹果菜单 → **关于本机** 查看系统和芯片。当前 DMG 支持 **Apple Silicon（M 系列芯片）**，要求 **macOS 14.4 或更高版本**；不适用于 Intel Mac。
2. 打开官方 [GitHub Releases 下载页](https://github.com/murphykfk/TranslateBar/releases/latest)，展开 **Assets**，下载 `.dmg` 文件。`Source code (zip)` 和 `Source code (tar.gz)` 是源码。
3. 双击下载的 DMG，将 **TranslateBar.app** 拖到旁边的 **Applications（应用程序）** 文件夹图标，等待复制完成。如果正在运行旧版，先从其菜单栏菜单选择“退出”后再替换。
4. 在访达侧边栏弹出 **TranslateBar** 磁盘映像。
5. 从访达 **应用程序 → TranslateBar** 双击启动。不要一直在 DMG 内运行，以免授权位置和实际使用位置不一致。

## 2. 首次打开与系统拦截

### 提示“从互联网下载，是否打开”

确认应用来自本仓库的 Releases 后，点击 **打开**。如果正常出现设置引导，直接进入第 3 节。

### 提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”

不同系统可能显示“Apple 无法验证 TranslateBar 是否包含可能危害 Mac 安全或泄漏隐私的恶意软件”等相近文字。确认下载来源可信且文件未遭改动后，按以下步骤针对这个应用确认打开：

1. 先从 **应用程序** 双击 TranslateBar 一次；关闭拦截提示，保留 App。
2. 打开苹果菜单 → **系统设置 → 隐私与安全性**（部分系统版本称“隐私与安全”）。
3. 向下滚动到 **安全性**，找到包含 **TranslateBar** 名称的拦截记录。
4. 点击 **仍要打开（Open Anyway）**。若要求验证，在系统窗口使用 Touch ID 或输入 **Mac 登录密码**。
5. 再次出现确认窗口时，点击 **打开**。如未自动启动，再从“应用程序”打开 TranslateBar。

获准后，当前版本通常可以直接双击打开；升级、更换路径或重新构建后，系统可能再次确认。无需为此关闭 Mac 的全局安全检查，也无需用户自行购买或创建签名证书。步骤依据 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，按钮名称可能因系统版本略有差异。

### 没有“仍要打开”按钮

- 先确认 **复制到了“应用程序”，并从那里尝试打开过一次**；然后关闭并重新打开“隐私与安全性”，滚动到“安全性”区域查看。
- 右键 →“打开”在你的系统上仍被拦截时，也使用上面的系统设置流程。
- 公司、学校管理的 Mac 可能不允许用户自行添加例外，此时需联系设备管理员；不要通过关闭整机安全策略来尝试安装。
- 仍无法处理时，记录完整提示、macOS 版本和芯片类型，到 [Issues](https://github.com/murphykfk/TranslateBar/issues) 反馈。不同拦截原因不能保证都能通过同一个按钮解决。

### 提示“已损坏”“将损坏你的电脑”或检测到恶意内容

**这些提示与普通开发者身份验证提示不同，不要直接套用上述放行步骤。**

- 若文件“已损坏”、DMG 无法挂载或复制失败，先从官方 Releases 重新下载，并按第 6 节核对 SHA-256。
- 若校验不一致，停止使用这份文件，重新下载；仍不一致则反馈问题。
- 若校验一致仍报错，或系统明确提示恶意内容／将损坏电脑，保留提示并反馈，等确认原因后再处理。依据 [Apple 对不同安全提示的说明](https://support.apple.com/zh-cn/102445)。

## 3. 保存自己的 API Key

1. 在“设置 TranslateBar”引导中粘贴自己的 **OpenAI API Key**，点击 **保存密钥**。
2. 确认密钥状态显示 **已保存到本机钥匙串**，再点“继续”。不需要创建 `.env` 或修改源码。
3. 可选地点击 **测试连接**。保存成功只代表本机存储成功；连接测试才会验证当前文字模型能否调用，并产生少量 API 费用。
4. 如果跳过了引导，可从 **菜单栏图标 → 设置… → 常规 → 设置引导…** 重新打开；也可在 **模型与 API** 中管理密钥和模型。

连接失败时，根据错误提示检查 Key、API 可用额度、网络及当前模型权限。ChatGPT 订阅不等于 API 额度。反馈问题时不要附上 Key。

## 4. 开启文字翻译权限

| 权限 | 用途 | 何时开启 |
| --- | --- | --- |
| 辅助功能（有些系统称“无障碍”） | 读取选中文字、定位输入框、回填译文 | 使用输入翻译或划词翻译时 |
| 输入监控 | 识别连续空格和全局快捷键 | 键盘监听未运行，且系统或应用提示需要时 |
| 录屏与系统录音 | 捕获所选应用的声音用于译声 | 首次开始译声时；文字翻译不需要 |

1. 在引导中点击 **前往授权…**，或手动到 **系统设置 → 隐私与安全性 → 辅助功能**。
2. 为 **TranslateBar** 开启开关。列表中没有它时，点击“＋”，选择 **应用程序** 文件夹中的 TranslateBar；需要解锁时在系统窗口完成验证。
3. 返回 TranslateBar，确认 **辅助功能：已授权**、**键盘监听：运行中**。总开关应处于启用状态；如显示监听未运行，可点击 **启用监听**。
4. 仅当提示需要时，到 **系统设置 → 隐私与安全性 → 输入监控** 为 TranslateBar 开启。
5. 若 macOS 要求重新打开应用，按提示退出并重开；也可在菜单栏选择退出后，从“应用程序”重新启动，再回到引导检查状态。

### 升级或重新安装后，原来的权限开关已经开启却不能翻译

当前下载包采用临时签名，升级、重新构建或更换位置后，旧版授权可能无法用于新版。卸载 App 也不一定清除系统中保留的旧授权记录。

从 0.4.6 起，应用会在每次启动及运行期间检查实际权限。开启文字翻译但权限尚未就绪时，会直接显示 **恢复输入与划词翻译**，保留原有 Key、语言与模型设置。选择“稍后处理”后，本次启动不会持续弹窗；菜单栏会显示权限异常，并保留 **恢复输入与划词翻译…** 入口。暂停总开关或关闭两项文字功能时，不会自动打开恢复引导。

1. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中选中 TranslateBar，点击 **“－”移除旧记录**。
2. 点击 **“＋”**，重新添加 **应用程序** 中当前安装的 TranslateBar，并开启权限。恢复页的 **在访达中显示当前 App…** 可以帮助确认正在运行的副本。
3. 从菜单栏退出 TranslateBar，再从“应用程序”重新打开。
4. 返回恢复页，确认 **辅助功能：已授权**、**键盘监听：运行中** 后点击“完成”。
5. 若辅助功能已授权但监听未运行，点击 **启用监听**；系统提示需要输入监控时，再为当前 App 开启。如输入监控中也保留旧记录，移除后重新添加，并按系统提示重开应用。

恢复权限无需重新填写已保存的 API Key。Apple 说明：[辅助功能权限](https://support.apple.com/zh-cn/guide/mac-help/mh43185/mac)。

如果随后显示 **钥匙串需要确认** 或 **需要解锁 / 重试**，到 **设置 → 模型与 API** 点击 **解锁 / 重试**，由你在系统窗口确认读取原有密钥。文字权限和钥匙串访问分别检查；应用不会因为一次读取失败而删除已保存的 Key。

## 5. 确认三种翻译能工作

### 输入翻译：原文被直接替换

1. 完成引导后，从 **菜单栏图标 → 设置… → 常规 → 翻译练习…** 打开独立练习框。
2. 输入“明天上午十点开会。”，先确认输入法选词，将光标留在这一段末尾。
3. 默认快速按 **四次空格**，等待翻译；该段文字应被英语译文直接替换。
4. 次数在 **输入翻译 → 连续按空格次数** 中设置，可选两次、三次或四次。只处理当前段落，回车分隔的其他段落保持原样。

若无反应，先检查总开关、输入翻译开关、监听状态及配置的空格次数；不要在被排除的终端或密码框中试用。

#### 微信输入框提示“当前控件未提供可访问文本”

1. 先升级到 **0.4.5 或更新版本**。0.4.5 的微信聊天输入替换已由用户手动确认。
2. 打开 **菜单栏图标 → 设置… → 常规 → 应用兼容性**，确认 **增强取词与回填兼容** 已开启（默认开启）。
3. 回到微信聊天输入框，完成输入和输入法选词后，按自己设置的次数连续空格，保持输入框聚焦并等待替换。

此兼容路径只处理 **光标前当前行**，不会自动发送消息。无法确认草稿或焦点已变化时保留原文。若仍然失败，反馈 macOS、微信与 TranslateBar 版本及完整提示即可；请不要提供私人聊天记录或 Key。

### 划词翻译：显示阅读浮窗

在支持文字选区的网页或文档中，选中一句英文；默认会显示中文译文浮窗。没有自动弹出时，保留选区，按 **⌃⌥T（Control + Option + T）**，并检查“划词翻译”开关和自动划词设置。不可复制的图片文字不支持；取消选择后浮窗通常会自动隐藏。

### 实时译声：首次使用再授予录制权限

1. 先在浏览器或其他应用中播放有讲话声音的视频。
2. 打开 **设置… → 实时译声**，启用该功能，选择正在播放视频的 **声音来源** 和输出语言。需要只听译声时，先开启 **译声期间静音原声**，再点击开始。
3. 按提示到 **系统设置 → 隐私与安全性 → 录屏与系统录音** 为 TranslateBar 开启权限。其他 macOS 版本可能使用“屏幕录制”等名称；以应用引导打开的系统页面为准。
4. **当前取音接口只开启“系统录音”仍不足**；请检查“录屏与系统录音”的授权。应用只接收所选来源的音频，不接收或上传画面，也不使用麦克风。
5. 系统要求重启时，退出并重新打开 TranslateBar，然后重新选择来源并开始。来源、语言与原声设置需要先停止译声后再调整。

如果来源列表没有所需应用，保持该应用运行并播放声音后刷新列表。译声捕获整个所选应用，不能隔离其中一个浏览器标签页。Apple 说明：[录屏和录音权限](https://support.apple.com/zh-cn/guide/mac-help/mchld6aa7d23/mac)。

翻译练习、连接测试和实际翻译可能产生 API 费用；输入与划词命中本地缓存时不调用 API。实时译声会持续使用 API，结束后请停止。

## 6. 可选：校验下载文件

在同一版本的 **Assets** 中下载 DMG 和 **SHA256SUMS.txt**，放到同一个文件夹，保留原文件名。例如两者都在“下载”文件夹时，在终端执行：

```sh
cd ~/Downloads
shasum -a 256 -c SHA256SUMS.txt
```

看到 DMG 文件名后显示 **OK**，表示其内容与该校验文件一致；这项校验不等于 Apple 公证。显示不一致或报错时，先核对文件是否来自同一发布版本、路径和文件名是否正确。

## 7. 关闭窗口后从哪里找应用

TranslateBar 常驻 **屏幕顶部菜单栏**。关闭设置窗口不会退出；点击菜单栏的翻译图标可重新打开“设置…”，或选择暂停、退出。升级后也请从“应用程序”启动固定位置的副本。
